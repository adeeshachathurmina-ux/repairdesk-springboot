# Portfolio Notes

## CV bullet
Built a role-secured electronic repair management platform using Spring Boot, React, MySQL and FastAPI, including repair workflow tracking, quotation management and an explainable repair-or-replace decision service.

## Interview structure
1. Problem: repair information is fragmented and customers cannot easily compare cost against device value.
2. Design: separated transactional workflow from recommendation logic using service boundaries.
3. Security: used BCrypt, JWT and role-based method authorisation.
4. Data integrity: used validation, database constraints, migrations and transactional services.
5. Responsible AI: started with transparent rules and documented the need for validated outcome data before training a model.
6. Next improvements: object storage for evidence images, notifications, audit events, CI/CD and model monitoring.
